# Waterford City example

```sh
pnpm build
pnpm --filter @toytown/example-waterford dev
```

## Points of interest

`public/data/pois.geojson` has fifteen places, in tour order from the Viking Triangle out to People's Park, each linked to its
OpenStreetMap building, with a short history and sources. The shared demo turns it into pins, a
tour list and popups (`startDemo({ pois })`, in `examples/shared/pois.ts`). The file format is
described in the [Castlemagner example](../castlemagner/README.md#points-of-interest-prototype).

## Data

`public/data/waterford.geojson` is generated by `pnpm data:waterford` (or `pnpm data:build` for both towns
plus the report) from Overpass, with:

- **bbox (w,s,e,n):** `-7.17,52.22,-7.05,52.28`

The admin boundary (relation 1645570) spans -7.187,52.210,-7.034,52.280. The residential, commercial, industrial and retail land use inside it spans -7.178,52.219,-7.042,52.276 (-7.160,52.222,-7.060,52.266 with the outer 2% trimmed). The chosen bbox covers the built-up city on both banks of the Suir, including Ferrybank, and gives 26,870 buildings. Bboxes were checked against Nominatim on 2026-09-29.
