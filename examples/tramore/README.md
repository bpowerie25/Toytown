# Tramore example

```sh
pnpm build
pnpm --filter @toytown/example-tramore dev
```

## Data

`public/data/tramore.geojson` is generated by `pnpm data:tramore` (or `pnpm data:build` for both towns
plus the report) from Overpass, with:

- **bbox (w,s,e,n):** `-7.18,52.135,-7.12,52.18`

The town place relation (14613896) spans -7.176,52.145,-7.132,52.179. The bbox extends south to 52.135 to include the Metal Man (way 46694890, at 52.1376,-7.1719, verified via Nominatim) on Great Newtown Head. It gives 6,272 buildings. Bboxes were checked against Nominatim on 2026-09-29.
